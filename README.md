# PulsePrice AI

AI-powered restaurant pricing platform that helps restaurants optimize menu prices using weather, foot traffic, and local event data.

## 🚀 Overview

PulsePrice AI is a Micro-SaaS concept designed to help small restaurants increase daily revenue through smart pricing recommendations.

The platform analyzes demand signals such as:

* 🌦️ Weather conditions
* 🚶 Local foot traffic
* 🎉 Nearby events

Based on these inputs, it suggests optimized menu prices to help restaurant owners maximize sales and improve profitability.

---

## ✨ Features

### Smart Price Recommendations

Generate AI-powered menu price suggestions based on real-time demand signals.

### Demand Forecast Dashboard

View demand scores, revenue opportunities, and customer traffic forecasts.

### Menu Management

Add, edit, and manage menu items and pricing.

### Analytics

Track demand trends and pricing recommendations through a modern dashboard.

### Dark Mode

Fully responsive interface with light and dark themes.

## ⚡ Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/pulseprice-ai.git
```

### Navigate to the Project

```bash
cd pulseprice-ai
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
